# Association Between Routine Childhood Immunization Coverage and Under-Five Mortality in Sub-Saharan Africa, 2000-2024

## Overview

Ecological panel study investigating associations between routine immunization coverage and under-five mortality in sub-Saharan Africa using publicly available UNICEF and World Bank data.

## Data Sources

- UNICEF Data
- World Development Indicators

## Software

- R 4.4.2
- Quarto
- VS Code

## Project Structure

- `data/`
- `scripts/`
- `tables/`
- `figures/`
- `manuscript/`
- `outputs/`
